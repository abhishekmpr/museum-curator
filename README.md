# Interactive Museum Exhibit Curator

## Description
A web application allowing users to design and manage virtual museum exhibits using a drag-and-drop interface.

## Features
- Drag and drop exhibit item placement
- Exhibit item types: artwork, artifact, display case
- User authentication for personal exhibit management
- Admin dashboard for exhibit management and user permissions

## Technologies
- Frontend: React
- Backend: Node.js
- Database: MongoDB

## How to Run
1. Clone the repository: `git clone https://github.com/username/museum-curator.git`
2. Install dependencies: `npm install`
3. Start the application: `npm start`

## Project Structure
- client: frontend application
- server: backend application
- models: database schema
- routes: API endpoints
- utils: utility functions
